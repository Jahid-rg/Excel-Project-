# Excel-Project-
# E-Commerce Sales Analysis Using Microsoft Excel

## Project Overview
This project focuses on analyzing e-commerce sales data using Microsoft Excel. The objective is to explore sales performance, profitability, customer segments, and product categories to generate meaningful business insights.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Analysis
- Data Visualization

## Project Structure

The workbook contains four main worksheets:

1. **Data:** Original sales dataset.
2. **1DATA:** Prepared and modified dataset.
3. **WORK:** Data analysis using Pivot Tables and charts.
4. **DASHBOARD:** Visual representation of sales analysis.

## Key Analysis Areas
- Sales Performance Analysis
- Profit Analysis
- Monthly Sales Trends
- Product Category Analysis
- Customer Segment Analysis
- Regional Sales Performance

## Objectives
- Analyze sales and profit performance.
- Identify important business trends.
- Understand customer and product performance.
- Present business insights through an interactive dashboard.
